# 🎟️ Event Ticket Booking System

A console-based **Event Ticket Booking System** developed using **C++**.

## 📌 Features

- Add new events
- View available events
- Book tickets
- View booked tickets
- Generate ticket IDs
- Supports Concert, Sports, and Theater events

## 🛠️ Concepts Used

- Classes and Objects
- Constructors and Destructors
- Inheritance
- Polymorphism
- Virtual Functions
- Function Overriding
- Operator Overloading
- Dynamic Memory Allocation

## 💻 Technology

- C++
